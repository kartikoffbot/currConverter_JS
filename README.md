# 💱 Currency Converter

A simple and responsive currency converter web application built with **HTML, CSS, and JavaScript**. It allows users to convert amounts between different currencies using exchange rate data fetched from an external API.

This was my first web development project, built as a way to practice DOM manipulation, working with APIs, and structuring a front-end project from scratch.

## 🚀 Getting Started

### Prerequisites

You just need a modern web browser. No additional installations are required.

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/kartikoffbot/currConverter_JS.git
   ```
2. Navigate to the project folder
   ```bash
   cd currConverter_JS
   ```
3. Open `index.html` in your browser

That's it — no build tools or dependencies needed!

## ⚙️ How It Works

1. The user selects a base currency and a target currency, and enters an amount.
2. The app sends a request to the exchange rate API to fetch the latest available rates (updated daily, not real-time).
3. The conversion is calculated using the fetched rate and displayed instantly on the page.
